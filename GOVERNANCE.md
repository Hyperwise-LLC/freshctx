# Governance

FreshCtx™ is an independent Apache-2.0 open-source project initially stewarded by Hyperwise. The complete usable v0.1 runtime, public schemas, adapter contract, examples, compatibility tests, and five initial adapters are part of the open project. Maintainers decide changes in public review against the versioned specification, security requirements, compatibility tests, and project scope. Contributor identity and commit attribution are preserved.

The v0.1 contract is frozen. Breaking changes require a documented proposal, migration guidance, and a new specification version. Guardian, Comply, and possible future commercial services for centralized governance, managed deployment, enterprise integrations, implementation, support, or SLAs are governed separately and are not FreshCtx core. These possible services are future-state; this statement does not claim they exist today.
